# AI slop blacklist

Ported from gstack plan-design-review. Instant suspicion if the brief (or the Safecracker's UI) leans on these:

1. Purple/violet/indigo gradients or blue-to-purple schemes as the identity
2. The 3-column feature grid: icon-in-colored-circle + bold title + 2-line description, repeated 3×
3. Icons in colored circles as section decoration
4. Centered everything
5. Uniform bubbly radius on every element
6. Decorative blobs, floating circles, wavy SVG dividers
7. Emoji as design elements (rockets in headings, emoji bullets)
8. Colored left-border on cards
9. Generic hero copy ("Unlock the power of…", "Your all-in-one solution")
10. Cookie-cutter rhythm (hero → 3 features → testimonials → pricing → CTA, equal section heights)
11. `system-ui` / `-apple-system` as the primary display/body font
12. Placeholder-as-label only
13. Body text < 16px or contrast < 4.5:1
14. Headings floating equally between paragraphs

Cards earn their existence — no decorative card grids. If deleting 30% of copy improves it, keep deleting.
